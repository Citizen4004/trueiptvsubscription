How to Set Up IPTV Smarters Pro

Few IPTV apps run on as many platforms as IPTV Smarters Pro, which makes it a common pick for mixed households. Loading your subscription into it only takes a few minutes.

Step by step

  1. Install the app. Grab it from the App Store on iOS, Google Play on Android, the Amazon Appstore on Firestick, or the official site for Windows and Smart TV builds.
  2. Choose how you'll log in. On the welcome screen, pick Login with Xtream Codes API or Load your playlist or file URL (M3U), whichever matches what you were given.
  3. Fill in your details. Xtream Codes needs a server URL, username, and password. M3U just needs the link. Name the profile whatever's easiest to recognize.
  4. Add the playlist. Confirm and give it a moment to pull in your channels and program guide.
  5. Start watching. Open Live TV from the home screen and browse.

Restricting content by category

If kids share the device, Smarters Pro's parental lock is worth setting up: Settings → Parental Control, set a PIN, then choose which categories need it to open. It's category-by-category rather than an all-or-nothing switch, so you can lock specific ones while leaving the rest accessible without a code.

Fixing a missing program guide

Sometimes an Xtream Codes login loads channels fine but the guide stays empty. If that happens, check the profile's settings for an "EPG URL" field, it's separate from the main login and needs its own URL pasted in. A blank guide is almost always this field being empty rather than anything wrong with your channel list.

Watching something that already aired

Where your channel's feed supports it, you can scroll back into the program guide and play something from earlier rather than only what's live right now, look for a small rewind icon on a past time slot. Whether this works depends entirely on the channel feed itself, not on the app, so it won't show up everywhere.

Frequently asked questions

Does IPTV Smarters Pro run on iPhone?

Yes, it's one of the few major player apps available on iOS as well as Android, Fire TV, and Windows.

What's the difference between the Xtream Codes and M3U login options?

Xtream Codes uses a server address plus a username and password. M3U uses a single playlist link. Use whichever your subscription provides.

Can I load more than one subscription into the app?

Yes, it supports multiple profiles, so you can add several playlists and switch between them.

How do I lock certain channel categories behind a PIN?

Go to Settings → Parental Control, set a PIN, and pick which categories to restrict. It applies per category, not to the whole app at once.
